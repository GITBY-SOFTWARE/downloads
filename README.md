# Gitby

Gitby helps your team avoid merge conflicts before they happen. Claim a file before you edit it,
see who holds every file in the repository, and hand files over when someone
else needs them. Git keeps doing everything it does today: commits, branches,
pushes and history.

Gitby runs in your terminal, and your team's dashboard is at
[gitby.cloud](https://gitby.cloud).

## Install

**macOS (Apple silicon) and Linux (x64)**

```sh
curl -fsSL https://github.com/GITBY-SOFTWARE/downloads/releases/latest/download/install.sh | sh
```

**Windows (x64), in PowerShell**

```powershell
irm https://github.com/GITBY-SOFTWARE/downloads/releases/latest/download/install.ps1 | iex
```

Then open a new terminal and run:

```sh
gitby
```

Update any time with `gitby update`.
