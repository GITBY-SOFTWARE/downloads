## New

- Install the terminal app on Linux, macOS or Windows, on x64 or ARM, with one command (`install.sh`, or `install.ps1` on Windows).
- Claim a file before you edit it and see who holds every file in the repository. Ask a holder to hand a file over, leave notes on files, and chat with your team, all in the terminal.
- Commit, push and sync from Gitby. A pre-push guard stops a push that carries a file someone else holds.
- A first-run setup: pick a theme, turn file icons on or off, and choose how sign-in opens. Run it again any time with `gitby setup`.
